# GDS Artifacts

This directory contains final GDSII layouts generated with OpenLane for both the Microwatt CPU core and the OpenFPGA-based fabric.

Contents
- [fpga_top.gds](https://github.com/s-m33r/openpower_hackathon_project/blob/main/gds/fpga_top.gds) — FPGA fabric GDS generated from OpenFPGA netlists using the flow in [fpga/config.json](../fpga/config.json). Top cell: `fpga_top`.
- [microwatt_wrapper.gds](https://github.com/s-m33r/openpower_hackathon_project/blob/main/gds/microwatt_wrapper.gds) — Microwatt CPU core-only GDS generated using [microwatt/config.json](../microwatt/config.json). Top cell: `microwatt_wrapper`.

Provenance summary
- Microwatt CPU: SoC peripherals and SoC/top wrappers were removed; only CPU pipeline/core modules were kept, wrapped by `microwatt_wrapper.v`, then run through OpenLane to produce `microwatt_wrapper.gds`.
- FPGA fabric: Verilog netlists were generated by OpenFPGA from the architecture task (e.g., `sofa_hd_custom`) and then run through OpenLane to produce `fpga_top.gds`.

How to view
- KLayout:
  - `klayout fpga_top.gds`
  - `klayout microwatt_wrapper.gds`

Notes
- PDK: SkyWater SKY130A with `sky130_fd_sc_hd` standard cells.
- Power nets follow `vccd1`/`vssd1` with `USE_POWER_PINS`.
- For generation details and reproducible steps, see:
  - CPU: [microwatt/README.md](../microwatt/README.md)
  - FPGA: [fpga/README.md](../fpga/README.md)
